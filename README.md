<section id="reflection" class="intro"><span class="kicker">A note from Vin</span><h2 class="section-title">My experience creating this blog</h2><p>My blog can be reached at the following link:</p><p><a href="https://vineam03.github.io" target="_blank" rel="noopener">https://vineam03.github.io</a></p><p>As an experience I think creating the blog and website was a good way to reflect my thoughts and findings and organize them into a mind map that I can present and articulate to other instructors. In terms of technical challenges, finding a free way to host the website and linting the code was the only problem I had to solve. In terms of site design, I wanted to organize the content of the page in a way that made logical sense and read like a narrative. This is important when developing a blog because readers shouldn’t have to search and connect the content of the blogs from different locations. I’m a really big fan of using bullet points too, so I added a section with bullet points for straightforward applications in regard to each resource. Brevity is quite important when it comes to blogs, and large blocks of text alone are not always effective. Presenting information with clear structure also matters in classrooms, where classroom organization is associated with student engagement and academic competence (Burgueño et al., 2024).</p></section>
<section id="teacher-blogs"><h2 class="section-title">Two teachers’ blogs, considered</h2>
<article class="teacher"><span class="teacher-label">Teacher blog 01 · ClassDojo</span><h2>Mr. Dylan Callens on ClassDojo</h2><p class="url"><a href="https://teachers-blog.com/classdojo-classroom-management" target="_blank" rel="noopener">https://teachers-blog.com/classdojo-classroom-management</a></p><p>My initial thoughts that this blog was laid out in a manner that made it easy for teachers to read things step-by-step. It does so by explaining features such creating and managing a unit in ClassDojo. Overall, I feel like there’s a very gradual and easy learning curve with this blog because of how the usage process is broken down into easy to digest chunks, for example the class roster QR code setup workflow being articulated.</p><p>My observation on the blog’s strengths is how well organized it is. As the primary example, this blog uses a numbering system for steps and then introduces how he applies the application in his classroom, another example being the point reward system, which each criterion for points being shown in the blog. This leads to the second strength of this blog, which is that he emphasizes that the functionality shouldn’t just be understood by the teachers but the students as well. He mentions how ClassDojo only works if students understand the system before you start using it. He then goes on in the blog by advising teachers to spend the first week explicitly teaching what each behavior looks like, rather than just naming it. An example mentioned in a class setting is one where the teacher shows students how the class display works by pulling it up on your projector and walking through a live example, so they know exactly what changes when a point gets awarded or removed. That emphasis on naming the specific behavior being recognized is useful because behavior-specific praise has been linked with improved student task engagement (Rathel et al., 2014).</p><p>My observation on areas of improvement includes more details in the point system on the negative end. This blog does a great job of teaching teachers how to assign points, but not how to handle point removal or disciplinary action. I also think that this blog neglects certain topics in greater detail, for example including privacy and school-policy guidance. The blog does mention student photos but could also address things like district rules, consent, data access. These omissions matter because adopting an online system by itself does not ensure better academic outcomes; how the tool is implemented alongside broader school practices matters (Kimmons, 2015).</p></article>
<article class="teacher"><span class="teacher-label">Teacher blog 02 · Google Classroom</span><h2>Ms. Caryn on Google Classrooms</h2><p class="url"><a href="https://carynlovesmath.com/google-classroom-organization-algebra/" target="_blank" rel="noopener">https://carynlovesmath.com/google-classroom-organization-algebra/</a></p><p>My initial thoughts are that this blog draws from extensive experience which spans many decades, to the point where the educational technologies mentioned were certainly adopted to improve the status quo. The blog mentions divided things lesson-by-lesson organization, each with their own set of components, backed by personal anecdotes makes it easier for teachers to relate to their classrooms. My observation of these blogs strengths, again, include that the organization of the blog is clear through usage of headings and lists. The action items suggested are also applicable immediately with things like lesson numbering convention and homework-document ideas. My observation on areas of improvement is that this teacher could have a walkthrough video that is more through then the current content and this would consist of going through the motions to recreate the displayed organization in a Google Classroom. I also think that a nice way to improve the blog would be by including downloadable like a sample lesson file for naming or running homework-document template.</p></article></section>
<section id="classdojo" class="post"><div class="post-head"><div class="icon">🌸</div><div><span class="kicker">Resource entry 01</span><h2>ClassDojo</h2></div></div><p>For my preferred classroom administrative tool, I would prefer using ClassDojo in the future. This is especially true when using it as a student facing application. Just as a brief overview, ClassDojo is a classroom platform for tracking student behavior, sharing updates, and communicating with families.</p><h3>How I would use ClassDojo in my classroom</h3><p>When it comes to managing classroom routines and behavior, I could use a small set of clear, positive behavior goals to recognize participation (like answering open-ended questions) and teamwork in collaborative assignments. I would teach students how the system works through an onboarding brief and use it consistently throughout class. I would focus feedback on the action students can repeat, since specific praise has been associated with stronger task engagement (Rathel et al., 2014).</p><p>When it comes to communicating and organizing with families, I could share brief classroom updates and communicate with families through the app with push notifications (all while following school privacy policies). I think at the start of the year, I would speak with parents about opting into this and trying to find alternatives for parents who are unable to do so.</p><div class="list-card"><h3>Some great applications for ClassDojo</h3><ol><li>Digital student portfolios for showcasing classwork</li><li>Student reflections on learning and progress</li><li>Photo and video updates from classroom activities</li><li>Two-way messaging between teachers and families</li><li>Translation of family messages into multiple languages</li><li>Scheduled announcements for families</li><li>Attendance-related alerts and reminders</li><li>Schoolwide stories and event updates</li></ol></div></section>
<section class="post"><div class="post-head"><div class="icon">💌</div><div><span class="kicker">Putting the tools together</span><h2>Classroom routines & family communication</h2></div></div><p>I will use these technologies in my classroom because together they help me reinforce clear classroom routines, recognize positive behaviors, and organize content in my class. Materials in my class would be significantly easier to find and access with Google Classroom and with ClassDojo I can enhance my overall ability to reward students for good behavior or performance in class. Family communication should be an intentional part of using these tools, since a review found promising outcomes when school family messages were positive, personalized, and two-way (See et al., 2020).</p></section>
<section id="google-classroom" class="post"><div class="post-head"><div class="icon">☁️</div><div><span class="kicker">Resource entry 02</span><h2>Google Classroom</h2></div></div><p>Another administrative tool I would use is Google Classrooms. As a reminder on a very abstract level Google Classrooms is a digital learning platform that helps teachers share course materials, assign and collect student work. It facilitates things like feedback, pushing class notifications and connects with the G-Suite of tools. Google Classroom’s main strength is its role as an organizational tool. The platform can bring materials and coursework together, while the instructional choices around those materials remain central to learning (Kimmons, 2015).</p><h3>How I would use Google Classrooms in my class</h3><p>When it comes to managing classroom routines and behavior, Google Classrooms would be used by me as an instructor to post the daily agenda, classroom expectations, instructions, reminders, and assignment deadlines. I think by creating a very standardized and consistent layout each day, that it would help students know where to find information and what they need to complete. To be honest, even though Google Classroom is not primarily a behavior-management tool, it certainly does support routines by making expectations and learning tasks clear. Making course expectations and the sequence of online and in-person work explicit can help students navigate blended learning (Heilporn et al., 2021).</p><p>When it comes to communicating and organizing with families, Google Classrooms would be great by using the guardian summaries feature which could help families stay informed about missing or upcoming work. Whilst doing this it’s also very important to follow school guidelines for family communication and use the platform to keep course information organized and accessible. Technology-based family communication has shown the most promise when messages are constructive and allow for meaningful two-way contact (See et al., 2020).</p><div class="list-card"><h3>Emerging applications for Google Classrooms</h3><ol><li>Assignments with interactive question types</li><li>Digital quizzes with automatic grading</li><li>Individualized practice and feedback</li><li>Student progress and engagement insights</li><li>Rubrics for clearer assessment</li><li>Integration with third-party learning tools</li><li>Guardian summaries of missing and upcoming work</li><li>Mobile access for assignments and announcements</li><li>Digital portfolios through linked Google tools</li><li>Connected Gemini support for planning and managing classwork, where available</li></ol></div><hr class="rule"><h3>Will I use these technologies in my classroom?</h3><p>I will use these technologies in my classroom because together they help me reinforce clear classroom routines, recognize positive behaviors, and organize content in my class. Materials in my class would be significantly easier to find and access with Google Classroom and with ClassDojo I can enhance my overall ability to reward students for good behavior or performance in class. Family communication should be an intentional part of using these tools, since a review found promising outcomes when school family messages were positive, personalized, and two-way (See et al., 2020).</p></section>
